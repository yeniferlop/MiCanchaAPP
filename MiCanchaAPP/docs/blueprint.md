# **App Name**: MiCanchaApp

## Core Features:

- Autenticación de Usuario: Autenticación segura de usuarios utilizando Firebase Authentication (correo electrónico/contraseña, inicios de sesión sociales).
- Calendario de Disponibilidad de Canchas: Muestra la disponibilidad de las canchas con una vista de calendario que muestra los espacios reservados y disponibles.
- Gestión de Reservas: Permite a los usuarios crear, ver, modificar y cancelar sus reservas de canchas.
- Notificaciones en Tiempo Real: Envía notificaciones en tiempo real para confirmaciones de reservas, recordatorios y cancelaciones.
- Integración de Pagos: Permite a los usuarios pagar sus reservas directamente a través de la aplicación utilizando pasarelas de pago seguras.
- Búsqueda de Canchas: Permite la funcionalidad de búsqueda que filtra los resultados según la fecha, la ubicación y la hora.

## Style Guidelines:

- Color primario: Azul Cielo (#87CEEB) para evocar una sensación de espacio abierto y deportividad.
- Color de fondo: Azul grisáceo claro (#D3E6F2) para una apariencia limpia y moderna.
- Color de acento: Azul profundo (#00008B) para proporcionar contraste y resaltar acciones importantes.
- Fuente del cuerpo y del encabezado: 'Inter', una fuente sans-serif que garantiza la legibilidad y una sensación contemporánea.
- Usa iconos con temas de fútbol para las características clave.
- Diseña un diseño receptivo para que se adapte sin problemas a varios dispositivos móviles.
- Implementa transiciones y animaciones sutiles para mejorar la participación del usuario al navegar por la aplicación.
